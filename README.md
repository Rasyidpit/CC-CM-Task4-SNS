# 🔔 Sesi Materi: Serverless Alerting (AWS SNS - 03 Oktober 2026)

Selamat datang di sesi materi Cloud Computing tanggal 3 Oktober 2026. Minggu ini, kita akan mempelajari bagaimana membuat sistem notifikasi otomatis menggunakan teknologi *serverless*.

---

## 🎯 Fokus Materi
Kita akan membangun sistem **Smart Room Monitor** yang mampu mendeteksi suhu ruangan dan mengirimkan peringatan otomatis ke email jika kondisi ruangan berbahaya.

## 🛠️ Services yang Digunakan
- **AWS Lambda**: Memproses data suhu.
- **AWS SNS**: Mengirimkan notifikasi email secara *real-time*.
